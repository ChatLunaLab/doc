# Agent Note: 首页

Status: implemented

## Problem

旧首页是 VitePress 默认的 hero、功能网格加一段会话日志演示，看不到产品本身，和任何一个文档站都差不多。中途有两版重做被否决：一版是带 Dock 的桌面场景，一版是平涂山丘的夜景插画。两版都是装饰，没有展示产品，后一版还显得廉价。

## Decision

- `docs/index.md` 使用 `layout: home` 和 `markdownStyles: false`。页面由 `docs/.vitepress/theme/components/home/` 下的组件和普通 HTML 区块组成，样式在 `docs/.vitepress/theme/styles/home.css`。
- `HomeHero.vue` 是首屏。它用原版 `/logo.png` 作应用图标，下面依次是标题「可组合的 Agent Harness，接入任何聊天平台。」、英文标语 "A composable agent harness for any chat platform."、「快速开始」链接，以及复制 `npm i -g chatluna` 的按钮。
- 首屏背景由 `HomeSky.vue` 绘制，是一个 WebGL 片元着色器写的流体网格渐变：几层正弦扭曲让坐标像液体一样流动，再用扭曲后的坐标把底色和四种流动的颜色混合起来。浅色模式用淡薰衣草紫、长春花蓝和丁香紫，保证深色标题清晰；深色模式用深靛蓝和紫。细颗粒噪点防止色带；画面里没有线条或高光，只有柔和的颜色。它表现得像水：指针移动时在身后拖出一道打旋的尾迹；滚动页面会搅动水面，让它流得更快、翻涌更大，然后慢慢平息。
- 着色器以一半分辨率、约 30 fps 渲染，只在可见时运行。开启「减少动态效果」时只渲染一帧，尺寸或主题变化时重画。第一帧出来之前，或者浏览器不支持 WebGL 时，显示 `.hero-sky` 上同色系的 CSS 渐变。
- 月亮前方是控制台轨迹页的 `AppWindow`。窗口一开始向后倾斜，随页面滚动立起，由一个节流的 scroll 监听写入 `--rise` 变量驱动。减少动态效果时窗口保持平放。
- `AppWindow.vue` 给截图和代码套上窗口：窗口按钮，再加居中的地址栏或等宽标题，由 `--app-bar-height` 和 `--app-radius` 控制尺寸。`HomeShot.vue` 把同一控制台页面的浅色、深色截图放进 `AppWindow`，按 `.dark` 类切换。
- 四个功能行左右交替：快捷设置、场景规则、聊天平台与模型、仪表盘与轨迹。每行一侧是简短文案和使用手册链接，另一侧是渐变面板（`.home-panel`，变体 `.is-dusk`），裁出一个控制台窗口。每块面板都运行自己的 `HomeSky`，`tone="panel"` 使用更深的配色；每个实例从流动中的随机位置开始，所以面板彼此不同。CSS 渐变保留为后备。
- 页面其余部分：
  - 两组分组列表，列出能力并链到使用手册；
  - 编辑器窗口里的插件示例；
  - npm / Docker / 源码三种安装命令，做成分段代码组；
  - logo 下方的社区链接。
- `docs/public/home/` 里的截图是 2 倍 WebP，1280×760 CSS 像素，中文界面加 mock 数据，各有浅色、深色两张。配置只通过快捷设置和场景规则展示，不截插件设置页。
- 标题使用主题自带的无衬线字体栈，不加载网络字体。宽度 960px 及以上时，滚过首屏后导航栏变成半透明模糊栏。

## Alternatives considered

- **保留 VitePress 的 hero 与 features frontmatter：** 放不下截图和滚动效果，外观也和其他 VitePress 站点一样。
- **带 Dock 的桌面场景：** 被否决，它在模仿操作系统，而不是展示产品。
- **带山丘和漂浮聊天气泡的夜景插画：** 被否决，显得廉价，气泡还挡住了截图。
- **canvas 点阵月亮，即把 logo 的半色调月牙放大到天空：** 被否决，看着别扭，一大片疏密不均的点更像纹理而不像月亮。
- **绕轨道转的平台名、月蚀日冕、极光帘幕、汇入窗口的粒子轨迹：** 做成草稿并排比较过，最后选了流体渐变，它更安静，也更衬大字标题。
- **CSS 滚动驱动动画：** 目标浏览器尚未全部支持。用一个监听器写 CSS 变量在所有浏览器都能用，并能退回静态布局。
- **支持平台的 logo 条：** 仓库里的图标集缺少 QQ 和飞书的标志，混用不同图标集又不统一，所以改在功能行文案里列出平台名。

## Consequences

- 控制台界面变化后需要重拍截图，mock 数据工具不在本仓库。
- 首屏的动效依赖 JavaScript 和 WebGL；没有它们时，页面只渲染 CSS 天空渐变和倾斜的窗口。
- `home.css` 全局引入，因此类名统一加 `home-` 前缀，唯一的导航规则限定在 `.VPNavBar.home`。
- `SessionLogDemo` 组件随旧首页一起删除。
