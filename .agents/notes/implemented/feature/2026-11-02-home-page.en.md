# Agent Note: Home Page

Status: implemented

## Problem

The home page used the default VitePress hero, a feature grid and a session-log demo. It showed nothing of the product and looked like any other documentation site. Two redesigns were rejected along the way: a desktop scene with a dock, and an illustrated night scene with flat hills. Both read as decoration rather than as the product, and the second felt cheap.

## Decision

- `docs/index.md` uses `layout: home` with `markdownStyles: false`. The page is built from components in `docs/.vitepress/theme/components/home/` and HTML sections styled by `docs/.vitepress/theme/styles/home.css`.
- `HomeHero.vue` is the opening screen. It opens with `HomeLogo.vue`, the console's own brand lockup with no app-icon frame: the dotted crescent mark and the "ChatLuna" wordmark, "Chat" in navy and "Luna" in violet. Then come the headline "可组合的 Agent Harness", the subline "接入任何聊天平台" at about 40% of its size in grey, the small English tagline "A composable agent harness for any chat platform.", a 快速开始 link, and a button that copies `npm i -g chatluna`. The headline drops punctuation and enlarges the Latin slightly, because Latin glyphs sit optically smaller than CJK at the same size.
- The copy fills the first screen, centered vertically; only the top edge of the console window peeks in at the bottom.
- Behind the hero, `HomeSky.vue` runs a WebGL fragment shader: a fluid mesh gradient. Five color points orbit slowly and blend by inverse distance, so each region keeps a distinct hue: periwinkle, violet, sky blue and lavender. Two layers of low-frequency simplex noise warp the coordinates so the borders between them flow like liquid in large, silky shapes. In the hero the color is composed as a moonrise: it pools at the bottom of the first screen below a slowly drifting horizon, the blobs orbit around that horizon, and the sky above fades to near-white (near-black in dark mode), so the headline sits on clean sky and the console rises out of the color. Panels have no horizon and are color all over. Fine grain prevents banding; there are no lines or highlights, only soft color. It behaves like water: the pointer drags a swirling wake behind it, and scrolling stirs the surface, so it flows faster and churns harder before settling again.
- The shader renders at half resolution and about 30 fps, only while it is visible. With reduced motion it renders one frame, and again on resize or theme change. Until the first frame, or when WebGL is unavailable, the `.hero-sky` CSS gradient in the same colors shows instead.
- Below the moon, the console's trace page sits in an `AppWindow`. It starts tilted back and straightens as the page scrolls, through one `--rise` variable written from a throttled scroll listener. With reduced motion the window stays flat.
- `AppWindow.vue` frames screenshots and code: window controls, then a URL pill or a monospace title. `--app-bar-height` and `--app-radius` scale it. `HomeShot.vue` puts the light and dark screenshots of one console page in an `AppWindow` and switches them with the `.dark` class.
- Four feature rows alternate sides: 快捷设置, 场景规则, 聊天平台 with models, and the dashboard with traces. Each row pairs short copy and a link into the manual with a gradient panel (`.home-panel`, `.is-dusk` variant) that crops a console window. Every panel runs its own `HomeSky` with `tone="panel"`, a deeper palette, and each instance starts at a random point in the flow so no two panels match. The CSS gradients remain as the fallback.
- The rest of the page:
  - capabilities as two grouped lists linking to the usage manual;
  - a plugin sample in an editor window;
  - the npm / Docker / source install commands as a segmented code group;
  - the community links under the same logo lockup.
- Screenshots in `docs/public/home/` are 2x WebP images, 1280×760 CSS px, of the Chinese UI with mock data, in light and dark. Configuration appears only through 快捷设置 and 场景规则, never the plugin settings page.
- Headings use the theme's sans stack. The only web font is Montserrat 600, subset to the letters of "ChatLuna" for the wordmark. When scrolled past the hero at 960px and wider, the nav becomes a translucent blurred bar.

## Alternatives considered

- **Keep the VitePress hero and features frontmatter:** it cannot host screenshots or scroll effects, and it looks like every other VitePress site.
- **A desktop scene with a dock:** rejected. It imitates an operating system instead of showing the product.
- **An illustrated night scene with hills and floating chat bubbles:** rejected as cheap. The bubbles covered the screenshot.
- **A canvas dot-matrix moon, the logo's halftone crescent at sky scale:** rejected as odd-looking; a large field of uneven dots read as a texture rather than a moon.
- **Orbiting platform names, an eclipse corona, aurora curtains, or particle trails converging on the window:** compared side by side as drafts; the fluid gradient was chosen as calmer and better suited to large text.
- **Fluid color over the whole hero:** rejected. With every area the same saturation and brightness there was no focal point, the headline sat on noise, and the folded shapes read as smoke.
- **CSS scroll-driven animations:** they are not available in every target browser. One listener writing a CSS variable works everywhere, and the page falls back to a still layout.
- **A logo strip of supported platforms:** the icon sets in the repository lack QQ and Feishu marks, and a mixed set looked uneven. The platforms are named in the row copy instead.

## Consequences

- Screenshots must be re-shot when the console UI changes. The mock-data tooling lives outside this repository.
- The hero's motion depends on JavaScript and WebGL. Without them, the page renders the CSS sky gradient and the tilted window.
- `home.css` is imported globally, so its classes are prefixed `home-`, and its only nav rule is scoped to `.VPNavBar.home`.
- The `SessionLogDemo` component was removed together with the old home page.
