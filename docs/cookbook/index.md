# 进阶指南 (Cookbook)

::: tip
本章面向已经完成 ChatLuna v2 基础部署，并需要进一步处理运维配置、版本迁移或网络拓扑的用户。
:::

本章汇总了进阶使用场景中的排错路径、迁移方案与网络接入指引。

## 章节简介

### 排错与诊断

当出现模型无法连通、机器人不回复消息、权限校验未通过或 WebUI 页面加载异常等问题时，请参考本节。本节提供了标准化的日志排查顺序与各组件链路的检查步骤。

### 命令行诊断

当控制台打不开、实例无法启动，或怀疑会话数据异常时，使用终端命令往往比图形界面更直接。本节区分了全局启动器与实例内置命令两个入口，并给出了常用的检查顺序。

### 从 v1 迁移

如果你正在使用旧版基于 Koishi 的插件模式，本节将指引你将现有配置与数据迁移至 ChatLuna v2 Harness 架构，平稳过渡到新版本。

### 反向代理与网络接入

当你需要从外部访问控制台时，本节说明了代理需要满足的条件、HTTPS 与子路径的配置方式，以及反向代理、SSH 隧道、内网 VPN 三种接入方式的取舍。安全相关的配置请参考 [公网部署](/manual/recipe/server)。
