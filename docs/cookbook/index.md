# 进阶指南 (Cookbook)

::: tip
本章面向已经完成 ChatLuna v2 基础部署并需要进一步处理运维配置、版本迁移或网络拓扑的用户。
:::

本章汇总了进阶使用场景中的排错路径、迁移方案和公网部署指引。

## 场景索引

你可以根据当前面临的任务或运维目标查阅对应小节：

| 章节 | 适合场景 |
| --- | --- |
| [排错与诊断](./troubleshooting) | 模型调用失败、消息无响应、指令权限被拦截、WebUI 状态异常等故障排查 |
| [从 v1 迁移](./migration) | 旧版 Koishi 插件环境用户平滑迁移至 v2 Harness 独立运行架构 |

## 章节简介

### 排错与诊断

当出现模型无法连通、机器人不回复消息、权限判定未通过或 WebUI 页面加载异常等问题时，请参考本节。章节内提供了标准化的日志排查次序与各组件链路的检查步骤。

### 从 v1 迁移

如果你正在使用旧版基于 Koishi 的插件模式，本节将指导你将现存配置与数据迁移至 ChatLuna v2 Harness 架构，确保历史环境向新版本平稳过渡。

### 公网部署与反代

当你需要将本地服务发布至公网环境时，本节将介绍如何配合反向代理服务器对外暴露 WebUI 服务、配置 SSL/TLS 证书加密链路，以及如何规划和维护多实例环境。
