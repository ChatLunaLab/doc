# 选择安装方式

ChatLuna v2 是一套独立部署的应用程序，而不是在已有 Koishi 实例中直接更新插件获得的新版本。在开始部署前，你需要根据自己的使用需求和运行环境选择合适的安装方式。

::: warning 版本说明
alpha 阶段引用的 npm 包名与镜像标签不保证在所有公共源同步发布。若在生产环境中试运行，请务必锁定经过验证的版本，并在升级前做好完整备份，切勿直接在生产实例上测试未知插件。
:::

## 安装方式对比

你可以参考下表快速选择适合你的安装方式：

| 方式 | 适合场景 | 环境要求 |
| --- | --- | --- |
| [Docker 安装](./docker) | 本机快速体验、服务器试运行 | Docker Engine 或 Docker Desktop |
| [命令行（CLI）安装](./cli) | 单机管理一个或多个实例 | Node.js 24+ |
| [从源码运行](./source) | 开发插件、调试框架核心 | Node.js 24+、Yarn 4 |

## 各方式的部署特征

这几种方式不仅安装命令不同，运行与维护机制也各有侧重：

- **Docker**：将运行环境、依赖与应用完整封装在容器内。运行时配置、数据卷持久化以及端口映射均通过 Compose 文件定义，后续升级只需拉取并替换镜像标签即可。
- **CLI**：通过命令行工具在本机的 `~/.chatluna/instances/` 目录下创建和管理实例文件。支持多实例共存，各个实例可独立启动、停止与配置。
- **源码运行**：直接克隆 v2 完整代码仓库，在 `packages/` 和 `plugins/` 目录中修改代码，配合热重载进行开发与调试。

## 下一步

选好适合你的安装方式后，阅读对应的安装指南即可开始部署：

- [通过 Docker 部署](./docker)
- [通过命令行工具（CLI）部署](./cli)

安装完成后，请前往 [快速上手](../quickstart) 完成实例的首次配置。
