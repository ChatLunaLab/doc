# 选择安装方式

::: tip
ChatLuna v2 是一套独立部署的应用程序，不是在已有 Koishi 实例中更新插件得到的新版本。先根据需求选择安装方式。
:::

| 方式 | 适合场景 | 环境要求 |
| --- | --- | --- |
| [Docker](./docker) | 本机快速体验、服务器试运行 | Docker Engine 或 Docker Desktop |
| [命令行（CLI）](./cli) | 单机管理一个或多个实例 | Node.js 24+ |
| [从源码运行](./source) | 开发插件、调试框架 | Node.js 24+、Yarn 4 |

- **Docker**：运行环境和依赖封装在容器中，配置、数据卷和端口在 Compose 文件中定义，升级只需替换镜像标签。
- **CLI**：在 `~/.chatluna/instances/` 下创建和管理实例，多个实例可以各自独立启停和配置。
- **源码**：克隆完整仓库，直接修改 `packages/` 和 `plugins/` 中的代码，配合热重载开发。

::: warning
alpha 阶段的 npm 包和镜像标签不保证在所有公共源同步发布。在生产环境试运行时，请锁定经过验证的版本，升级前做好备份，不要在生产实例上测试未知插件。
:::

安装完成后，前往 [快速上手](../quickstart) 完成首次配置。
