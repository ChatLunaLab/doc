# 快速上手

::: tip
本节带你走完从「第一次打开控制台」到「机器人在聊天平台里回你消息」的完整路径。在开始之前，请确保你已经[安装并启动](./starter/)了实例。
:::

当你在终端中看到启动成功的日志后，就可以准备进入控制台了。

首次启动实例时，终端日志里会打印出一个带有临时登录口令的访问链接。你只需复制并在浏览器中打开该链接，即可直接进入控制台管理界面。

控制台默认的本地访问地址为：

`http://127.0.0.1:5028`

进入登录页后，如果发现页面要求输入口令，但你之前不小心关闭了终端日志，也可以直接在登录页面点击「忘了口令？」，页面会给出清晰的指引，帮助你快速重置口令并重新登入。

<!-- 截图占位：登录页，包含口令输入框与「登录」按钮 -->

登录成功后，页面中央会自动弹出「新手引导」向导窗口。

在新手引导窗口的顶部，展示了一条清晰的三步进度条：

- **AI 模型**：为机器人接入对话与推理能力
- **平台与主人**：连上聊天软件并认领最高控制权
- **做什么用**：设定机器人的职责场景与个性偏好

在引导过程中的每一步，都提供了「先跳过这步」按钮。如果你希望稍后手动调整，随时可以跳过。

哪怕不小心关闭了引导窗口也不用担心。在控制台进入「设置」页面，找到「新手引导」，就能随时重新走一遍完整的向导流程。

<!-- 截图占位：新手引导首页，展示三步进度条与「重新走一遍新手引导」入口 -->

## 第一步：连上 AI 模型

要让机器人开口说话，首先要为它接通大语言模型。

在新手引导的第一页「连上 AI 模型」中，我们需要完成提供商的授权与模型选择：

1. **挑选服务商并填写凭据**：点击提供商下拉菜单，挑选你所使用的 AI 服务商。选中后，下方会随之展开对应的配置项表单。在表单中填入你在服务商后台获取到的 API Key；如果你使用的是自建网关或代理，可以在（需要时）显示的接口地址输入框中填入对应的接口地址。
2. **测试连接**：信息填好之后，先不要急着点下一步，点击表单下方的「测试连接」按钮。系统会尝试调用服务商接口进行一次真实握手。当看到界面提示测试通过时，说明凭据与网络连接均正常，下一步按钮也会随之解锁。如果「测试连接」没有通过，向导将无法进入下一步。这时需要检查 API Key 是否完整粘贴、网络代理是否通畅，或者接口地址格式是否正确。
3. **选定默认模型**：测试连接通过后，在下方的「默认模型」下拉列表中挑选中意的模型。所有新创建的会话，都会默认使用该模型来处理请求。

如果在打开提供商列表时，发现模型目录完全是空的，这通常是因为对应的提供商插件尚未安装。遇到这种情况，可以先点击跳过本步，在控制台进入「插件」页，搜索并安装对应的提供商插件，装好后再回来完成模型配置。

## 第二步：连接平台并绑定主人

模型接入完成后，下一步是让机器人连接到具体的聊天平台，并确立你的所有者身份。

新手引导在这一步为你规划了两个出口：如果你准备将机器人接入实际的聊天群或应用，可以前往「聊天平台」页添加适配器；如果你目前只想先在浏览器里体验对话，也可以直接选择先在网页里聊。

<!-- 截图占位：平台步骤，包含「连上聊天平台」入口与已连接账号列表 -->

如果你选择接入真实的平台，可以打开「聊天平台」页面，点击添加你所需的平台适配器。在弹出的适配器配置面板中，填入对应平台的账号凭据并保存。

稍等片刻，观察页面中的账号列表。当账号状态变成「在线」时，就说明机器人已经成功登录平台了。

连接成功后，在欢迎向导中点击「私聊绑定」按钮。此时屏幕中央会弹出一个私聊绑定窗口，界面上会清晰展示一串随机生成的六位绑定码。

接下来，请按照以下步骤完成主人身份的绑定：

1. **发起私聊**：打开聊天平台，使用你自己的平台账号找到刚刚上线的机器人，发起私聊会话。
2. **发送绑定指令**：在私聊对话框中，发送 `/bind` 并在后方空格附带这串六位码，例如发送 `/bind 123456`。
3. **在控制台认领**：发送成功后切回控制台页面，在绑定窗口中的「最近私聊」列表中确认出现了你自己的平台账号，点击右侧的「认领为主人」按钮。

为了保障控制安全，这串六位绑定码在生成后十分钟内有效。如果连续输错五次，该码就会立刻作废。如果超时失效或输错超限，可以在弹窗中点击「换一个」按钮，系统会即时刷新并重新生成一串全新的绑定码。

如果由于平台自身限制导致机器人与你实在无法私聊，也可以点击弹窗底部的「无法私聊？手动填写用户 ID」链接。在展开的输入框中，直接填入你自己在该聊天平台中的用户 ID 并确认，同样可以完成绑定。

绑定主人是系统安全的核心环节。被认领的主人账号会直接拿到系统的最高权限等级。只有当消息发送者拥有主人身份后，机器人才会响应并执行修改配置、重启实例等特权操作。

<!-- 截图占位：私聊绑定弹窗，包含六位绑定码、复制按钮与失效倒计时 -->

::: warning
不要把绑定码发给别人。任何用这串码完成绑定的账号都会成为主人，等同于拿到这个实例的最高权限。
:::

## 第三步：它是做什么的？

完成了平台接入与身份认证后，向导的最后一步是确定机器人的应用场景。

在这个页面中，你会看到两个代表不同方向的功能卡片，你可以根据实际需要进行二选一：

- **个人助手**：主要在私聊里回答问题、查资料、调用工具、写代码、定时提醒。
- **伪装**：有人设和说话风格，在群里像真人一样聊天，有作息、心情和长期记忆。

如果选择「伪装」模式，需要先安装与之配套的角色引擎。如果系统检测到当前尚未安装引擎，页面会弹出提示引导你前往安装。

选定场景卡片后，点击右下角的「完成，去私聊」按钮退出新手向导。

此时机器人会通过聊天平台的私聊对话主动向你发来问候，一步步询问你的喜好，包括期望它叫什么名字、拥有怎样的性格特征以及平日的说话习惯。收集完成后，它会自动为你生成专属的人设档案。

即使现在还不确定理想的人设也没关系，后续随时可以在私聊中发送 `/setup` 指令，机器人便会重新发起配置对话，方便你随时修改调整。

## 跑通一次对话

所有基础配置就绪后，我们终于可以和机器人进行第一次互动了！

建议先在最省事的地方进行验证：打开「聊天」页，进入内置的网页聊天室。新建一个会话，在底部输入框输入一句话并按下回车。

片刻之后，你会看到模型的回复以流式打字机的效果逐字呈现出来。

与此同时，页面左侧的会话列表会自动把本次对话归档记录下来。打开「轨迹」页，还能看到本轮对话的完整执行过程——包括模型在提示词中看到了什么输入、在生成答案时具体调用了哪些工具等内部细节。

<!-- 截图占位：聊天页，展示一次流式回复与会话列表 -->

在控制台网页内验证完毕后，我们再回到真实的聊天平台中走完最后一公里。

打开聊天平台客户端，向机器人发送一条私聊消息。

当你收到机器人发回的文字气泡时，就意味着整套端到端调用链路已经彻底跑通：消息经由平台适配器接入，经过内部路由分发给角色引擎与 Agent 逻辑，再交由 AI 模型完成推理与生成，最后通过渲染投递模块将回复安全送回你的聊天界面。

至此，你的机器人已经正式就位，可以开始陪伴你的日常工作与交流了！
