# 快速上手

::: tip
本节带你走完从「第一次打开控制台」到「机器人在聊天平台里回你消息」的完整路径。前提是你已经[安装并启动](./starter/)了实例。
:::

首次启动时，日志里会打印一个带口令的登录链接，点开即可进入控制台。默认地址是 `http://127.0.0.1:5028`；如果忘了口令，可以在登录页点「忘了口令？」按提示重置。

<!-- 截图占位：登录页，包含口令输入框与「登录」按钮 -->

进入控制台后会自动弹出「新手引导」：顶部是三步进度条（AI 模型 → 平台与主人 → 做什么用），每一步都可以「先跳过这步」，之后从「设置」里的「新手引导」重新走一遍。

<!-- 截图占位：新手引导首页，展示三步进度条与「重新走一遍新手引导」入口 -->

## 第一步：连上 AI 模型

在「连上 AI 模型」里选择一个提供商，填入 API Key 和（需要时）接口地址。

1. 点「测试连接」，先确认能真的完成一次调用。
2. 测试通过后，选择一个默认模型——新会话都会用它。

「测试连接」没通过就不能进入下一步；如果模型目录是空的，多半是提供商插件还没安装，先在「插件」页装上再回来。

<!-- 截图占位：模型步骤，包含提供商选择、API Key 输入、测试连接与默认模型下拉 -->

## 第二步：连接平台并绑定主人

新手引导提供两个出口：去「聊天平台」页添加适配器，或者先在网页里聊。

<!-- 截图占位：平台步骤，包含「连上聊天平台」入口与已连接账号列表 -->

添加适配器时填好平台凭据，等账号状态变成「在线」。之后在欢迎向导里点「私聊绑定」，页面上会出现一串六位绑定码：

1. 用你自己的平台账号私聊机器人。
2. 发送 `/bind` 加上这串码。
3. 回到控制台，确认「最近私聊」里出现了你的账号，点「认领为主人」。

绑定码十分钟内有效，输错五次就作废，点「换一个」重新生成。实在无法私聊时，可以点「无法私聊？手动填写用户 ID」，直接填入你的平台账号 ID 再确认。

被认领的主人账号会拿到最高权限等级；拥有主人身份后，机器人才会执行特权操作。

<!-- 截图占位：私聊绑定弹窗，包含六位绑定码、复制按钮与失效倒计时 -->

::: warning
不要把绑定码发给别人。任何用这串码完成绑定的账号都会成为主人，等同于拿到这个实例的最高权限。
:::

## 第三步：它是做什么的？

这一步选择机器人主要的使用场景：

- **个人助手**：主要在私聊里回答问题、查资料、调用工具、写代码、定时提醒。
- **伪装**：有人设和说话风格，在群里像真人一样聊天，有作息、心情和长期记忆。

选择「伪装」时需要先安装对应的角色引擎，页面会给出提示。选好后点「完成，去私聊」，机器人会在私聊里询问名字、性格和说话习惯，然后生成人设。之后随时发 `/setup` 可以重新调整。

<!-- 截图占位：用途步骤，包含「个人助手」「伪装」两张卡片与各自的说明 -->

## 跑通一次对话

先在最省事的地方验证：打开「聊天」页，新建会话发一句话，回复应该会流式出现。左侧会话列表会记录这次对话，「轨迹」页能看到本轮完整过程——模型看到了什么、调用了哪些工具。

<!-- 截图占位：聊天页，展示一次流式回复与会话列表 -->

接着回到聊天平台，私聊机器人发一条消息。收到回复就说明端到端已经打通：平台适配器 → 路由 → 引擎 → Agent → 模型 → 渲染投递。
