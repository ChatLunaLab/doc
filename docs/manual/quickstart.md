# 快速上手

::: tip
本节带你完成从「能打开 WebUI」到「机器人在聊天平台回复消息」的完整路径。假设你已经[安装并启动](./starter/)了实例。
:::

打开 `http://127.0.0.1:5028`，用首次启动时生成的口令登录（见对应安装方式的「首次登录」小节）。

## 配置一个模型

进入「模型」页面，添加一个提供商 (Provider)：

1. 选择提供商类型（OpenAI 兼容、Anthropic、Gemini 等）。
2. 填入 API Key 与基础地址。
3. 保存后点「测试」，确认能拿到模型列表并完成一次真实调用。

可用的模型会自动进入模型目录。如果你的提供商是按需安装的，市场会提示先安装对应的 provider 插件。

## 绑定主人身份

机器人需要知道谁是主人，才能执行特权指令。进入「设置 → 主人」，或在任意会话里运行绑定指令，输入绑定码完成绑定。

## 接入聊天平台

进入「适配器」页面，添加一个平台适配器（Satori 协议下的 QQ、Telegram、Discord 等），填入平台要求的凭据。适配器上线后，消息会进入路由引擎。

## 跑通一次对话

回到「聊天」页面，新开一个会话，发一条消息。你应该能看到回复流式出现，并在「轨迹」里看到这一轮的完整过程：模型看到了什么、调用了什么。

接着去你的聊天平台给机器人发条消息，确认端到端走通。
