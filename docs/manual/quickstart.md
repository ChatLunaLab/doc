# 快速上手

::: tip
本节带你走完从「第一次打开控制台」到「机器人在聊天平台里回你消息」的完整流程。在开始之前，请确保你已经[安装并启动](./starter/)了实例。
:::

终端显示启动成功的日志后，即可进入控制台。

首次启动实例时，终端日志中会打印带有临时登录口令的访问链接。复制并在浏览器中打开该链接，即可直接进入控制台。

控制台默认的本地访问地址为：

`http://127.0.0.1:5028`

如果打开页面后要求输入口令，而你已经关闭了终端日志，可以点击登录页中的「忘了口令？」，按照提示重置口令并重新登录。

<!-- 截图占位：登录页，包含口令输入框与「登录」按钮 -->

登录成功后，页面中央会自动弹出「新手引导」窗口。

窗口顶部展示了三步进度：

- **AI 模型**：为机器人接入对话与推理能力
- **平台与主人**：连接聊天软件并认领最高控制权
- **做什么用**：设定机器人的职责场景与个性偏好

引导过程中的每一步都可以点击「先跳过这步」，稍后再手动配置。

如果不小心关闭了引导窗口，也可以前往「设置」页面，点击「新手引导」随时重新打开。

<!-- 截图占位：新手引导首页，展示三步进度条与「重新走一遍新手引导」入口 -->

## 第一步：连上 AI 模型

要让机器人开始对话，首先需要接入大语言模型。

在新手引导的第一步「连上 AI 模型」中，需要完成模型提供商的授权与模型选择：

1. **选择服务商并填写凭据**：在提供商搜索框中查找或浏览你使用的 AI 服务商，点击选中卡片后，下方会展开对应的配置表单。在表单中填入从服务商获取的 API Key；如果使用自建网关或代理，也可以在接口地址输入框中填入对应的地址。
2. **测试连接**：填好信息后，点击表单下方的「测试连接」按钮。系统会调用服务商接口进行测试。提示测试通过后，「下一步」按钮即可点击。如果测试未通过，则无法进入下一步，请检查 API Key 是否完整、网络代理是否通畅，以及接口地址格式是否正确。
3. **选择默认模型**：测试连接通过后，在下方的「默认模型」下拉列表中选择要使用的模型。后续所有新建的会话都会默认使用该模型。

如果打开提供商列表时没有任何模型，通常是因为对应的提供商插件尚未安装。此时可以先跳过这一步，前往「插件」页面搜索并安装对应的插件，安装完成后再回来配置模型。

## 第二步：连接平台并绑定主人

接入模型后，下一步是让机器人连接到聊天平台，并绑定你的主人身份。

这一步提供了两种使用方式：如果你准备将机器人接入聊天软件，可以前往「聊天平台」页面添加适配器；如果只想先在浏览器中体验对话，也可以直接在网页中聊天。

<!-- 截图占位：平台步骤，包含「连上聊天平台」入口与已连接账号列表 -->

如果你选择接入真实平台，前往「聊天平台」页面，点击添加所需的平台适配器。在弹出的配置面板中填入该平台的账号凭据并保存。

稍等片刻，当页面中的账号状态变为「在线」时，表明机器人已经成功登录平台。

连接成功后，在新手引导中点击「私聊绑定」按钮。此时会弹出私聊绑定窗口，并显示一串随机生成的 6 位绑定码。

接下来按照以下步骤绑定主人身份：

1. **发起私聊**：在聊天平台中使用你的个人账号找到刚刚上线的机器人，发起私聊。
2. **发送绑定指令**：在私聊中发送 `/bind` 并附带 6 位绑定码（例如 `/bind 123456`）。机器人回复确认消息后即绑定成功，无需再返回控制台确认。

如果此前已经在私聊中给机器人发送过消息，绑定窗口的「最近私聊」列表中会出现你的账号，直接点击右侧的「认领为主人」即可完成绑定，无需输入绑定码。

为确保安全，6 位绑定码在生成后 10 分钟内有效。连续输错 5 次后，该绑定码会立即作废。如果绑定码超时或失效，点击弹窗中的「换一个」按钮即可重新生成。

若因平台限制无法与机器人发起私聊，可以点击弹窗底部的「无法私聊？手动填写用户 ID」，在展开的输入框中填入你在该平台的用户 ID 并确认，同样可以完成绑定。

绑定主人是保障系统安全的重要步骤。认领成功的主人账号拥有系统的最高权限，修改配置、重启实例等特权操作仅在发送者为主人时才会执行。

<!-- 截图占位：私聊绑定弹窗，包含六位绑定码、复制按钮与失效倒计时 -->

::: warning
不要把绑定码发给别人。任何用这串码完成绑定的账号都会成为主人，等同于拿到这个实例的最高权限。
:::

## 第三步：它是做什么的？

完成平台接入与身份认证后，向导的最后一步是确定机器人的使用场景。

页面中提供了两张功能卡片，可以根据需要选择：

- **个人助手**：主要用于私聊中回答问题、查资料、调用工具、写代码和定时提醒。
- **伪装**：拥有人设与说话风格，可以在群聊中像真人一样聊天，具备作息、心情与长期记忆。

如果选择「伪装」模式，需要先安装配套的角色引擎。如果检测到尚未安装引擎，页面会提示你前往安装。

选择场景卡片后，点击右下角的「完成，去私聊」按钮即可退出新手引导。

此时机器人会在聊天平台的私聊中主动发送问候，询问你的偏好（包括机器人的名字、性格特征和说话习惯等）。收集完成后，它会自动生成专属的人设档案。

如果暂时还没想好人设，后续也可以随时在私聊中发送 `/setup` 指令重新发起配置。

## 跑通一次对话

完成基础配置后，就可以开始和机器人进行第一次对话了。

建议先在网页中验证：前往「聊天」页面，进入内置的网页聊天室。新建一个会话，在底部的输入框中输入消息并回车。

等待片刻，模型的回复会以流式打字机效果逐字显示。

与此同时，页面左侧的会话列表会记录本次对话。前往「轨迹」页面，还可以查看本轮对话的完整执行过程，包括模型接收到的提示词内容，以及生成回复时调用的工具等细节。

<!-- 截图占位：聊天页，展示一次流式回复与会话列表 -->

在控制台中验证完成后，我们回到聊天平台中测试真实对话。

在聊天平台中向机器人发送一条私聊消息。

收到机器人的回复后，表明整个调用链路已经完全跑通：消息经由平台适配器接收，由内部路由分发至角色引擎与 Agent 逻辑，交由 AI 模型完成推理与生成，最后通过渲染投递模块将回复发送至你的聊天窗口。

至此，机器人已经配置完成，可以正常使用了。
