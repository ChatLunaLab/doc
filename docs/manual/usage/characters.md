# 角色与预设

::: tip
本节介绍「预设」和「伪装」两个页面：前者管理人格与提示词，后者管理机器人的角色形象。
:::

预设 (Preset) 决定机器人「以什么人格说话」，角色 (Character) 决定它「在群里看起来是谁」。两者在设计上相互解耦、组合使用：预设提供提示词模板与核心人格设定，角色提供昵称、头像与外貌描述。

## 管理预设

前往「预设」页面。界面的左侧是预设列表，右侧是当前选中预设的编辑区。

预设文件是一段带有 frontmatter 元数据的 Markdown 文本：

```markdown
---
name: 助手
description: 友善的通用助手
---

你是 {name}，一个友善的助手。回答简洁，先给结论。
```

- **frontmatter**：位于文档头部的 `---` 区域，包含 `name`、`description` 等字段，用于声明预设的基础信息。
- **模板正文**：渲染后注入模型系统提示词 (System Prompt)。正文支持变量插值（如 `{name}`）与分节指令。

::: tip
修改预设时，建议直接在右侧源码编辑器中编辑并保存，避免在表单字段间来回拼接。详见[预设：源码优先](/guide/extend/prompts)。
:::

在实际运行中，你可以在单条会话中动态切换预设以调整口吻，也可以通过路由规则在不同上下文间分发预设。

## 配置角色伪装

前往「伪装」页面管理机器人的角色身份。一个完整的角色包含三个部分：

- **形象**：设置昵称、头像和外貌描述，让机器人在聊天环境中展现为具体的个人形象。
- **人格**：定义性格特质、语言风格与背景设定，该部分会作为提示词的一部分参与生成。
- **记忆关联**：绑定与该角色专属相关的长期记忆条目。

角色与预设互相独立：同一个角色形象可以根据对话场景切换搭载不同的预设，同一个预设也可以挂载到多个不同的角色上。

## 绑定场景规则

预设与角色通常不需要全局生效。你应该通过场景规则将其定向应用到特定的频道或群组。

例如：
- 在工作群组中，通过规则绑定严肃高效的「助理」预设；
- 在闲聊群组中，通过规则绑定包含特定头像与昵称的「朋友」角色形象。

具体的会话路由配置步骤，请参阅[场景规则](./rules)。
