# 定时与后台任务

::: tip
本节介绍如何使用「定时任务」与「后台任务」页面及相关指令，让机器人在无需人工干预的情况下按时执行或在后台异步处理任务。
:::

## 定时任务

定时任务 (Schedule) 支持在指定时刻单次触发、按固定频率周期性触发，或在满足特定条件时触发机器人。

### 触发方式

在创建定时任务时，你可以通过以下选项指定触发机制：

- **`--at <时间>`**：在指定的时刻触发一次。
- **`--every <间隔>`**：每隔一段固定的时长触发一次（如周期性轮询）。
- **`--cron <表达式>`**：按照 Cron 表达式规则周期性触发。
- **`--watch <表达式>`**：持续关注特定变化，当满足条件时触发。

### 管理定时任务

你可以直接在控制台的「定时任务」页面创建和管理任务，也可以在聊天环境中使用 `chatluna.schedule` 指令完成操作。

添加任务示例：

```text
chatluna.schedule add --cron "0 9 * * *" --reason "每天早上发昨日总结"
```

查看与控制现有任务：

```text
# 查看所有定时任务列表
chatluna.schedule list

# 暂停指定任务
chatluna.schedule pause <id>

# 恢复指定任务
chatluna.schedule resume <id>

# 立即手动触发一次任务
chatluna.schedule fire <id>

# 删除指定任务
chatluna.schedule remove <id>
```

### 配置判定模型

在定时任务与关注 (`--watch`) 任务中，系统通常需要判断「当前是否应当触发」以及「如何对内容进行总结」。这一流程由角色为 `@decide` 的判定模型负责处理。

::: warning
如果未在路由或模型配置中为 `decide` 角色分配具体模型，定时任务的条件判定与总结步骤将无法正常执行。
:::

请前往模型配置或路由设置页面，为 `decide` 指定具备充足逻辑决策能力的模型。

## 后台任务

后台任务 (Background) 用于处理执行耗时较长、不应阻塞当前对话会话的操作。

你可以前往「后台任务」页面查看当前正在运行的任务列表、执行进度以及历史任务的最终结果。
