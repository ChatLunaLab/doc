# 场景规则

::: tip
场景规则决定机器人「在什么场合、对谁、用什么方式说话」。同一个机器人可以在 A 群扮演活泼的角色、在 B 群只回答技术问题、在某个私聊里保持安静，不需要部署多份实例。
:::

场景规则的核心思路是**把默认行为和特殊情况分开**：先配置一套全局设置，再在需要特殊对待的群聊或私聊中覆盖个别配置项。收到消息时，系统会匹配适用的规则，按从通用到具体的顺序叠加，得出当前会话的完整配置。把机器人拉进新群时，只需设置这个群的差异项。

## 认识页面

在侧边栏点击「配置」→「场景规则」。页面顶部是目标选择器，右上角是保存按钮，中间是按功能分类的配置标签页。

### 目标选择器

- **全局**：所有消息的默认配置，没有单独规则的群聊或用户都使用这里的设定。
- **机器人**：针对某个平台上的具体机器人账号，适合同时登录多个账号时区分差异。
- **群聊**：只对某个群生效，最常用。
- **私聊用户**：只对某个用户的私聊生效，不影响该用户在群里的交互。
- **群成员**：只对某个群内的指定成员生效，适合单独给群主或管理员开放权限。

选择目标后，右侧的「设好的规则」卡片会用自然语言说明生效条件，例如「在群 123456 中，同时满足：平台是 onebot」。条件互相冲突时（例如同时限定群聊和私聊），卡片会标红并给出修改建议。

### 标签页

- **基本**：用途（由哪个引擎处理消息）、模型、思考深度和人设。
- **回复**：触发条件、连发合并、群聊记录和主动搭话。
- **能力**：工具、技能、子代理、长期记忆和指令。
- **安全**：权限等级、执行环境和消息审核。
- **高级**：聊天记录切分、机器人自身消息是否计入历史、显示格式和对话压缩。
- **引擎专属标签页**：把用途切换为「伪装」等引擎时出现，用来调整作息、心情、动作或思考方式。

安装新插件或切换用途时，相关设置项会自动出现或隐藏，无需刷新。

## 继承与覆盖

每个字段只有两种状态：

- **继承**：不设置独立的值，沿用外层（通常是全局）的设定。
- **覆盖**：为当前目标指定一个新值。

选好目标后直接修改字段即可覆盖，只有改过的字段才会保存到当前规则，其余字段会随全局配置自动同步。字段右上角菜单中的「恢复默认」让该字段重新继承，「放弃修改」把整块表单恢复到打开时的状态。

例如全局设置了基础模型、「智能助理」人设和网页搜索工具。想在「内部测试群」试用推理模型，只需选中这个群，把「模型」改掉并保存。之后全局修改人设时，测试群会同步更新，模型则保持测试群自己的设定。

::: tip
覆盖按字段生效，而不是按页面。保存时页面会提示哪些改动只影响新会话、哪些即时生效。
:::

### 保存与冲突

保存时系统会校验规则版本。如果你编辑期间有其他管理员保存了同一目标的规则，页面会提示冲突并阻止覆盖，需要刷新后重新修改。保存成功后规则立即生效。

## 多条规则怎么叠

一条消息同时匹配多条规则时，按「越具体越优先」逐层叠加，后叠加的覆盖先前的同名字段：

1. 全局规则在最底层。
2. 条件越具体的规则越靠后。
3. 具体程度相同时，优先级数值大的靠后。
4. 优先级也相同时，创建早的靠前；仍相同则按内部标识排序。

「具体」指条件的范围类型：限定群号的「群聊」规则比只限定平台的「机器人」规则更具体，「群成员」规则又比「群聊」规则更具体。

::: warning
优先级只用于微调同一层级内多条规则的先后，不要用它代替「群聊 → 群成员」这种天然的范围层级。
:::

条件冲突的规则不会匹配任何消息，保存前请按摘要卡片的提示修正。

例如全局人设是「默认助手」，「日常交流群」覆盖为「群管家」，再为群主单独配置一条群成员规则覆盖为「私人秘书」。普通群员呼叫时命中全局和群聊两条规则，人设是「群管家」；群主呼叫时三条全部命中，人设是「私人秘书」。

## 常见配置

推荐的流程是：先在「全局」配置通用的用途、模型和人设；再切换到目标群，只修改不同的字段；需要完全不同的任务时切换「用途」并在引擎专属标签页中微调；保存后在群里发消息测试，可以在规则摘要和轨迹页面查看实际命中的规则。

### 给某个群换人设

选择「群聊」并选定目标群，在「基本」标签页修改「人设」并保存。如果新预设依赖状态、作息等角色引擎能力，还要把「用途」改为「伪装」。

### 让某个群完全沉默

选定目标群，把「用途」改为「不回复」并保存。比把机器人移出群更轻量，还能保留记录（取决于「群聊记录」设置），随时切回原来的引擎即可恢复。

### 只让某个群用某个模型

选定目标群，在「基本」标签页的「模型」下拉框中选择专用模型。下拉列表来自「提供商」页面中已配置的模型，找不到时先去那里添加。

### 群里只对某个人开放

把目标类型切换为「群成员」，指定群和成员，再修改「人设」「模型」或「权限」。例如公共群的权限设为只读，再给管理员单独一条群成员规则，权限设为完全放行。

### 私聊单独一套

选择「私聊用户」并选定用户，覆盖「人设」「模型」或「权限」。私聊不会打扰其他人，可以放宽工具权限；也可以反过来对陌生用户收紧权限。

## 标签页都管什么

### 基本

- **用途**：由哪个引擎处理消息。默认「对话」；「伪装」用于角色扮演，「编码」用于代码工作流，「设置」用于首次配置引导。
- **模型**：回复时使用的模型，留空沿用上层。
- **思考深度**：模型支持时控制推理强度，档位取决于模型。
- **人设**：绑定的预设，从下一回合起生效。

### 回复

- **什么时候回复**：@、引用、称呼、私聊和随机搭话等触发条件。
- **连发消息**：收到即回复，或等对方说完再合并回复。
- **群聊记录**：不回复时是否记录、回填条数、回复中收到新消息的处理和图片提供方式。
- **主动说话**：冷场搭话、稍后继续、话题插话和早晚安问候。

### 能力

- **工具**：使用策略（直接提供全部、先检索后调用、写代码调用、委派给子代理）和允许/禁用列表。
- **技能**：允许/禁用列表，以及是否允许技能使用已保存的密钥。
- **子代理**：默认模型、最高档位、委派深度、允许的配置文件和后台驱动。
- **长期记忆**：自动提取、主动回忆、存储位置，以及按预设还是按会话隔离。
- **指令**：模型可以执行的指令列表，未列出的需要管理员确认。

### 安全

- **权限**：只读、文件、自动、完全放行四档，留空时按用户权限等级决定。
- **执行环境**：默认执行代码的机器和允许委派的机器。
- **消息审核**：屏蔽词、记录词和内容替换规则。

### 高级

- **聊天记录**：共享模式（全员共用、每人一份、自定义规则）和对话分区通道。
- **机器人发出的消息**：是否计入对话历史。
- **显示**：回复格式（纯文本、富消息、Markdown）、可用元素、分条方式、隐藏元素、引用和分段长度。
- **对话压缩**：上下文达到设定比例时自动压缩，以及是否使用模型自带的压缩能力。

## 与快捷设置、插件配置的关系

- **插件配置**：插件本身的运行参数，例如数据库重试策略，在「插件配置」页面调整。
- **快捷设置**：面向新手的精简入口，修改的就是场景规则中的「全局」配置。
- **场景规则**：完整的分层配置，快捷设置的改动会同步到这里，还可以按群聊、用户覆盖。

## 常见问题

**改了全局配置，某个群没变化**：这个群有更具体的规则覆盖了该项。切换到这个群，对该项点击「恢复默认」并保存。

**保存后没有立即生效**：「用途」「模型」「聊天记录」「工具」「指令」是会话级设置，活跃的旧会话继续沿用旧值，新会话才生效；「人设」「什么时候回复」「群聊记录」「显示」「长期记忆」在下一条消息就生效。

**规则无法匹配**：检查摘要卡片是否标红，群号和平台是否填错。条件无误时，到轨迹页面查看实际命中的规则链。

**一条规则能管多个群吗**：可以。群号输入框可以填多个，满足任意一个即可。
