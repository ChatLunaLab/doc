# 接入聊天平台

::: tip
本节介绍「聊天平台」页面的使用方法：通过适配器 (Adapter) 将外部即时通信 (IM) 平台接入你的 ChatLuna 实例。
:::

ChatLuna 通过统一的 Satori 协议接入各聊天平台。每个适配器实例对应一个具体的平台账号（如经由 OneBot 协议连接的 QQ、Telegram、Discord 等）。适配器的主要职责包括：

- 将各平台的原生消息转换为标准化的内部事件，并移交路由引擎处理。
- 将机器人的回复内容重新转换为对应平台的原生消息格式并下发。

单个 ChatLuna 实例支持同时运行多个适配器与多个账号。

## 添加适配器

你可以通过图形界面添加并配置适配器：

1. 打开控制台，进入「聊天平台」页面。
2. 点击添加适配器，在列表中选择你需要的平台类型。
3. 根据所选平台填写连接凭据与配置项：
   - **OneBot / QQ**：填写 OneBot 实现端提供的 WebSocket 端点（Endpoint）与访问令牌（Token）。
   - **Web**：控制台内置的 WebUI 渠道，用于在后台直接与机器人对话排查问题，无需配置外部凭据。
   - **其他 Satori 适配器**：各平台适配器以独立插件形式提供（例如 `@satorijs/adapter-onebot`）。若列表中未显示目标平台，请先前往「插件市场」页面搜索并安装对应插件。

适配器连接成功上线后，接收到的平台消息会自动进入路由引擎，由场景规则决定分配给哪个引擎或角色处理。

::: warning
若适配器的连接端点配置错误或凭据无效，适配器将无法维持与平台的长连接，导致该账号下的消息接收与发送中断。
:::

## 区分平台与机器人身份

在适配器配置中，系统通过两个核心字段标识消息来源：

- `platform`：平台类型名称（例如 `onebot`）。
- `selfId`：当前适配器所登录的机器人账号唯一标识（ID）。

在场景规则的 `scope`（作用域）过滤配置中，你可以同时指定这两个字段以精确圈定响应范围。例如，你可以设定规则为：仅当消息来自 `onebot` 平台、当前响应的机器人账号为 `12345`、且处于群组 `678` 时才触发特定逻辑。
