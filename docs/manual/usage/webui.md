# 认识 WebUI

::: tip
控制台是 ChatLuna 的主界面。装好之后，几乎所有配置、调试和管理操作都在这里完成，聊天平台那边只负责收发消息。
:::

第一次启动 ChatLuna 时，你会看到一个本地的网页地址。用浏览器打开它，登录进去，就是控制台。

这一页不打算逐个功能展开——每个功能在后面的章节里都有自己的页面。这里只做一件事：让你先认识这个界面，知道什么东西大致在哪一栏。

## 打开与登录

在浏览器里访问实例的地址，默认是本机的 5028 端口。

首次启动会进入欢迎向导，流程大致是：

1. 创建管理账号（或者按向导提示绑定）。
2. 连接一个模型提供商。
3. 选择默认模型。
4. 完成，进入控制台。

如果你是通过聊天平台第一次接触机器人，可能会收到一个绑定码。在聊天里发送绑定指令、输入这个码，就能把自己的账号设为主人。

::: warning
控制台拥有实例的完全管理权限。公网部署时务必开启登录认证并配置 HTTPS，不要把未鉴权的控制台直接暴露在互联网上。
:::

## 界面结构

登录之后，界面分成三块：

- **左侧导航栏**：按分组排列的页面入口。
- **顶部**：当前页面标题、账号菜单、通知。
- **右侧内容区**：当前页面的列表、表单或详情。

导航栏的分组是固定的六个：

| 分组 | 放什么 |
| --- | --- |
| **概览** | 仪表盘，快速了解实例正在发生什么 |
| **对话** | 聊天页、伪装（角色）页 |
| **配置** | 预设、提供商、聊天平台、场景规则、快捷设置 |
| **插件** | 已安装的插件与插件市场 |
| **能力** | 工具、权限、技能、环境、记忆、MCP、表达方式 |
| **观测** | 轨迹、用量、日志、后台任务、定时任务 |

具体页面会随安装的插件增减。比如没装 MCP 相关插件，「能力」组里就没有 MCP 页。

### 页面一览

| 页面 | 地址 | 作用 |
| --- | --- | --- |
| 仪表盘 | `/dashboard` | 实例状态总览，各插件会往这里放卡片 |
| 聊天 | `/chat` | 与机器人对话，验证配置是否走通 |
| 伪装 | `/character` | 角色状态、关系、群画像等 |
| 预设 | `/presets` | 人格、提示词与角色设定的管理 |
| 提供商 | `/providers` | 模型服务连接、模型清单与模型角色 |
| 聊天平台 | `/adapters` | 平台适配器与账号 |
| 场景规则 | `/routing` | 按群、按人、按条件覆盖行为 |
| 快捷设置 | `/control` | 面向新手的聚合设置页 |
| 插件 | `/plugins` | 已安装插件的启用状态与配置 |
| 市场 | `/market` | 搜索、安装插件 |
| 工具 | `/tools` | 工具清单、策略与可见性 |
| 权限 | `/permissions` | 等级、模式、审批规则 |
| 技能 | `/skills` | 技能目录、导入与覆盖关系 |
| 环境 | `/machines` | 执行机器与工作区 |
| 记忆 | `/memory` | 长期记忆条目 |
| MCP | `/mcp` | 外部 MCP 服务 |
| 表达方式 | `/expressions` | 角色可用的表达素材 |
| 轨迹 | `/traces` | 每一轮对话的完整过程 |
| 用量 | `/usage` | Token 与费用统计 |
| 日志 | `/logs` | 运行时日志 |
| 后台任务 | `/background` | 长时间运行的任务 |
| 定时任务 | `/schedule` | 定时与关注任务 |

::: tip
地址栏里的路径可以直接收藏。排查问题时，把某个会话的轨迹链接发给别人，对方打开就能看到同一份记录（前提是他也有控制台权限）。
:::

## 定制导航栏

导航栏可以按你的习惯整理：

- 拖动页面调整顺序。
- 把页面拖进自建的分组。
- 隐藏平时用不到的页面。

如果改乱了，在侧边栏的管理入口里选择恢复，所有页面会回到各插件声明的默认位置。

## 三种常见的操作模式

不同页面长得不一样，但操作方式大致可以归成三类。

### 列表 + 抽屉

大多数管理页是这种：左边或中间是一组卡片/列表，点开某一项，右侧滑出抽屉显示详情。

抽屉顶部通常有几个操作按钮，比如「测试连接」「设为默认」「删除」；底部是「取消」和「保存」。

### 分组表单

「场景规则」「快捷设置」这类页面，内容被切成若干个标签页，每个标签页里是一组相关设置。

修改之后记得保存。很多页面会提示「有未保存的修改」，切换标签页或离开时可能会提醒你。

### 实时视图

「聊天」「轨迹」「日志」属于这一类：内容会随着运行实时变化，不需要刷新页面。

聊天页里，模型正在生成时能看到逐步输出；轨迹页里，新一轮对话会自己冒出来。

::: warning
保存不等于立刻生效。不同设置的作用时机不一样：有的下一次对话就生效，有的要等新会话建立。页面上通常会有说明，拿不准时看提示。
:::

## 仪表盘

仪表盘是「先看整体」的地方。

它由各个插件贡献的卡片拼成，常见的包括：

- 最近的用量与花费。
- 消息量与活跃会话。
- 运行状态、版本与更新提示。

卡片会随着安装的插件变化。如果你觉得某些卡片没用，可以在卡片菜单里隐藏它。

## 快捷设置

如果你刚接触 ChatLuna，觉得「场景规则」里的选项太多，可以先从「快捷设置」开始。

它把最常用的几件事集中在一页：

- 回复行为（要不要回复、什么时候回复）。
- 模型与推理档位。
- 工具、记忆、子代理等能力的总开关。
- 角色与预设的默认选择。

这里的设置会作为「全局默认」写进去，之后可以到场景规则里针对具体群再覆盖。

## 设置页

「设置」页放的是与控制台本身相关的东西：

- 外观：浅色、深色或跟随系统。
- 语言：界面语言。
- 账号：密码、登录状态。
- 访问令牌：给外部工具或脚本调用的凭据。

设置页默认在导航栏里是隐藏的，可以从侧边栏的收纳区或账号菜单进入。

::: tip
如果你在用脚本调用控制台接口，令牌就在这一页生成。令牌等于账号权限，别把它写进公开的脚本或聊天记录。
:::

## 移动端

控制台可以在手机上打开，布局会自动收窄：导航栏变成抽屉，表格变成卡片。

日常查看状态、审批工具调用、在聊天页里对话都没问题。复杂的批量配置还是建议在电脑上做。

## 常用操作

以下几件事，几乎每天都会用到：

**看一轮对话发生了什么。**
「轨迹」页找到那个会话，点进某一轮，能看到每次模型请求、每次工具调用和最终回复。

**临时关掉某个工具。**
「工具」页搜到它，把策略切到禁用。下一个回合就生效。

**给某个群单独设置。**
「场景规则」里新建一条规则，选中那个群，改你想改的项。

**装一个新插件。**
「市场」里搜索、安装，然后在「插件」页确认它已启用。

**看今天的花费。**
「用量」页，按模型和会话分组查看。

## 排查

**打不开控制台。**

确认进程在运行、端口没有被占用、防火墙允许访问。公网部署还要检查反向代理的转发规则。

**登录后一片空白。**

多半是前端资源没加载出来。清一次缓存、换一个浏览器再试；如果只有某个页面空白，那可能是插件版本不匹配。

**某个页面不见了。**

对应插件可能被停用或卸载了。去「插件」页看看。

**改了设置没反应。**

先确认点过保存；再确认这项设置是否要等新会话才生效；最后去场景规则里看有没有更高优先级的规则覆盖了它。

**导航栏乱掉了。**

用侧边栏管理入口恢复默认布局。
