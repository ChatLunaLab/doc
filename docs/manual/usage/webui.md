# 认识 WebUI

::: tip
控制台是 ChatLuna 的核心管理面板。完成安装后，几乎所有配置修改、状态调试和日常管理都在这里完成，聊天平台那边只负责收发消息。
:::

第一次启动 ChatLuna 时，终端里会输出一个本地的网页地址。用浏览器打开它并登录，就进入了控制台的主界面。

我们在这里不打算把所有功能一次性展开——每个独立模块在后续章节中都有专属的详细介绍。本篇只做一件事：带你迅速熟悉控制台的界面布局，清楚各项功能大致分布在什么位置。

<!-- 截图占位：控制台首页 · 仪表盘 -->

## 打开与登录

在浏览器中直接访问实例地址即可打开控制台，默认是本机的 `5028` 端口。

如果是首次启动，系统会自动引导你进入欢迎向导。整个过程非常简单，大致只需四步：

1. 创建管理员账号，或者按向导提示完成绑定。
2. 连接一个模型提供商。
3. 选定一个默认使用的模型。
4. 点击完成，正式进入控制台。

如果你是通过聊天平台初次接触机器人，可能会收到一条包含绑定码的消息。直接在聊天窗口中发送绑定指令并带上这个码，就能将自己的聊天账号设为最高权限的主人。

::: warning
控制台拥有对整个实例的完全控制权。若要部署在公网环境中，请务必启用登录认证并配置 HTTPS，切勿将未经鉴权的控制台直接暴露在互联网上。
:::

## 界面结构

成功登录后，控制台的主界面主要由三部分组成：

- **左侧导航栏**：按功能分类排列的页面入口，随时切换视图。
- **顶部栏**：展示当前所在的页面标题、当前登录的账号菜单以及系统通知。
- **右侧内容区**：呈现当前页面的主要内容，包括数据列表、配置表单或详情面板。

左侧导航栏默认划分为六个固定的功能分组：

| 分组 | 放什么 |
| --- | --- |
| **概览** | 仪表盘，帮助你快速把握实例正在发生的事情 |
| **对话** | 聊天交互页面，以及角色的伪装设定 |
| **配置** | 人格预设、模型提供商、聊天平台、场景规则与快捷设置 |
| **插件** | 已安装插件的管理面板与扩展市场 |
| **能力** | 工具、权限、技能、执行环境、记忆、MCP 与表达方式 |
| **观测** | 对话轨迹、Token 用量、系统日志、后台任务与定时任务 |

导航栏中的页面并非一成不变，而是会根据当前安装的插件动态增减。例如，如果你尚未安装 MCP 相关插件，在「能力」分组中就不会出现 MCP 页面。

### 页面一览

这里整理了各个页面的访问路径与具体用途，方便你在需要时随时查阅：

| 页面 | 地址 | 作用 |
| --- | --- | --- |
| 仪表盘 | `/dashboard` | 想看实例整体状况时去；能看到关键指标、运行状态与各插件推送的信息卡片 |
| 聊天 | `/chat` | 想验证配置或直接测试对话时去；能看到网页端实时交互界面与模型生成过程 |
| 伪装 | `/character` | 想调整角色扮演细节时去；能看到角色当前状态、人际关系与群画像分析 |
| 预设 | `/presets` | 想定制人设与提示词模板时去；能看到人格提示词列表、角色模板与设定项 |
| 提供商 | `/providers` | 想接入或切换底层大模型时去；能看到模型服务商连接状态、模型清单与角色分配 |
| 聊天平台 | `/adapters` | 想连接具体聊天软件时去；能看到各聊天软件适配器的在线状态与登录账号 |
| 场景规则 | `/routing` | 想针对不同群聊定制行为时去；能看到按群或按人覆盖的规则列表与条件配置 |
| 快捷设置 | `/control` | 新手想快速搞定常用开关时去；能看到聚合在一处的常用配置项与全局默认参数 |
| 插件 | `/plugins` | 想管理本地扩展功能时去；能看到已安装插件的运行状态、开关与具体配置项 |
| 市场 | `/market` | 想探索并安装新扩展时去；能看到插件应用中心、搜索列表与一键安装入口 |
| 工具 | `/tools` | 想管理机器人可调用的能力时去；能看到外部工具列表、调用策略与可见性设置 |
| 权限 | `/permissions` | 想规范各项功能的使用资格时去；能看到权限等级划分、操作模式与审批规则 |
| 技能 | `/skills` | 想查看或导入专属技能包时去；能看到技能目录、导入工具与技能间的覆盖关系 |
| 环境 | `/machines` | 想管理脚本运行沙箱时去；能看到已接入的执行机器列表与隔离工作区配置 |
| 记忆 | `/memory` | 想检查或修剪机器人的长期记忆时去；能看到持久化记忆条目与检索记录 |
| MCP | `/mcp` | 想挂载外部协议服务时去；能看到已连接的 MCP 服务器、可用资源及连接状态 |
| 表达方式 | `/expressions` | 想丰富机器人的回复语气与素材时去；能看到表情包、语调动作等可用素材库 |
| 轨迹 | `/traces` | 回答异常或想复盘决策流程时去；能看到单轮对话的完整思考链、工具调用与上下文 |
| 用量 | `/usage` | 想核对模型开销与额度时去；能看到按模型、会话和时间统计的 Token 费用报表 |
| 日志 | `/logs` | 遇到系统报错或排查故障时去；能看到系统运行时的实时输出日志与错误栈 |
| 后台任务 | `/background` | 想查看长时间运行的异步作业时去；能看到后台任务的当前进度、状态与耗时 |
| 定时任务 | `/schedule` | 想配置定时提醒或周期动作时去；能看到所有定时计划任务与自动触发规则 |

::: tip
浏览器地址栏中的路径支持直接收藏和分享。排查问题时，你可以直接把某个会话的轨迹页面链接复制给协作者，对方打开就能看到完全一致的调试记录（前提是对方同样拥有控制台访问权限）。
:::

## 定制导航栏

左侧导航栏并不是完全固定的，你可以根据自己的使用习惯自由定制：

- 拖拽任意页面以调整它们的前后显示顺序。
- 将页面拖动到自建的专属分组中集中管理。
- 将平时几乎用不到的低频页面收起或隐藏。

如果中途调整得有些混乱，随时可以在侧边栏底部的管理菜单中选择恢复默认布局。所有页面都会瞬间重新归位到各插件预设的初始位置。

## 三种常见的操作模式

不同页面的具体用途虽然各有千秋，但在交互模式上主要可以归纳为以下三类：

### 列表 + 抽屉

大多数管理页面都采用了这种经典的布局方案。页面的左侧或中央展示一组卡片或数据列表，点击其中的某一项后，右侧会自动滑出抽屉面板显示详细信息。

抽屉顶部通常放置常用的操作按钮，例如「测试连接」「设为默认」或「删除」；底部则固定着「取消」和「保存」按钮，修改完后随时可以提交或放弃。

### 分组表单

像「场景规则」与「快捷设置」这一类设置项较多的页面，通常会将内容组织在多个标签页中，每个标签页聚焦一组相关的配置项。

在调整任何选项后，请务必记得点击保存。如果检测到未保存的变动，控制台通常会在页面顶部给出醒目的修改提示，或者在你准备切换标签页与离开页面时弹出挽留提醒。

### 实时视图

像「聊天」「轨迹」与「日志」这类页面属于实时渲染的动态视图。页面内容会随着机器人的实际运行自动推流更新，无需你手动刷新浏览器。

例如在聊天页面中，你可以直观地看到模型正在生成的流式文本；而在轨迹页面里，机器人新收到消息并处理完成后，对应的对话记录就会自动出现在列表顶端。

::: warning
点击保存并不等同于所有设置都会立刻在当前对话中生效。不同设置的生效时机存在差异：部分选项在下一句回复时就会起效，而涉及上下文架构的设置则可能需要等新会话建立。页面上通常会有明确的小字说明，如果不确定，多留意界面给出的提示。
:::

## 仪表盘

仪表盘是登录控制台后首先看到的页面，也是让你「先看全局」的中枢。

这里的内容由各个启用的插件按需注册的数据卡片组合而成，常见的卡片包括：

- 最近的 Token 消耗与费用走势。
- 近期的消息吞吐量与活跃会话数。
- 实例核心服务的运行状态、当前版本号与更新提示。

卡片呈现的内容会随着你安装的扩展而丰富。如果你觉得部分卡片并不关心，可以直接在卡片右上角的菜单中选择隐藏它。

## 快捷设置

如果你刚开始接触 ChatLuna，觉得「场景规则」里错综复杂的条件设置有些繁琐，那么不妨先从「快捷设置」入手。

这个页面把普通用户最常调整的几项核心行为整理到了一起：

- 回复行为：设置机器人在什么时机参与对话、是否允许主动发言。
- 模型与档位：选择默认主力模型以及推理参数的档位。
- 基础能力开关：一键开启或关闭工具调用、记忆检索以及子代理等能力。
- 角色与预设：为机器人挑选默认的人格设定与对话模板。

在快捷设置中保存的修改会作为整个系统的「全局默认配置」。等你后续熟悉了之后，随时可以前往场景规则页面为特定的群聊或私聊单独配置覆盖项。

## 设置页

与管理机器人行为的页面不同，「设置」页专门用来管理控制台本身的基础环境与账号：

- 外观偏好：可在浅色模式、深色模式或跟随系统外观之间自由切换。
- 语言设置：调整控制台的显示语言。
- 账号安全：修改管理员登录密码，或查看当前会话的登录状态。
- 访问令牌：为外部自动化脚本或第三方工具生成调用控制台 API 的鉴权令牌。

为了保持侧边栏的整洁，设置页在默认状态下是收起隐藏的。你可以通过侧边栏底部的收纳菜单或者右上角的账号头像菜单快速进入。

::: tip
如果你正在编写脚本调用控制台的接口，所需的鉴权 Token 就在本页面中生成。令牌具备该账号拥有的全部控制权限，请妥善保管，切勿将其直接提交到公开的代码仓库或发送在公开聊天群中。
:::

## 移动端

控制台针对移动端设备做了专门的响应式适配。使用手机或平板的浏览器打开时，页面布局会自动重排为单栏结构：左侧导航栏转为折叠抽屉，复杂的数据表格也会自适应重组为便于触控的纵向卡片。

在移动设备上随时随地查看运行状态、快速审批待办的工具调用或者在聊天页面与机器人临时测试都非常流畅。不过对于批量修改规则等精细配置，依然建议在桌面端大屏幕下操作。

## 常用操作

在日常使用 ChatLuna 的过程中，以下几项操作是最频繁遇到的：

**想要复盘一轮对话的具体细节**  
前往「轨迹」页面找到目标会话并点击对应的轮次。在这里你能清晰地看到每一次发送给模型的提示词、模型的思考推导、工具调用的入参与返回，以及最终送出回复的完整链条。

**临时停用某个不稳定的工具**  
打开「工具」页面，在搜索栏中输入工具名称，将其调用策略直接切换为禁用。该改动在接下来的下一轮交互中立即生效。

**为某个特定的群聊单独调整人设**  
前往「场景规则」页面新建一条规则，在作用对象中勾选目标群聊，随后调整需要单独定制的模型或预设项即可。

**安装并启用一个新插件**  
进入「市场」页面搜索你想要的插件并点击安装。安装完毕后跳转至「插件」页面，确认该插件的状态处于启用即可开始使用。

**核算今日的模型使用成本**  
切换至「用量」页面，按模型类型或者会话分组筛选，即可一目了然地查看当天的 Token 消耗总量与预估费用。

## 排查

在使用控制台的过程中若遇到非预期情况，可以参考以下思路排查：

**无法打开控制台页面**  
首先检查后台进程是否仍在正常运行，其次确认默认端口未被其他程序抢占，并检查本地防火墙或安全组是否放行了该端口。若是公网环境，还需确认反向代理配置中的端口转发与 WebSocket 代理规则是否正确。

**登录后页面显示一片空白**  
这种情况多数是浏览器本地缓存导致前端静态资源加载失败。可以尝试强制刷新、清除浏览器缓存，或者切换至无痕模式重试。如果仅有某一个插件页面出现空白，则通常是由于插件版本与控制台核心存在兼容性差异所致。

**导航栏中找不到某个功能页面**  
这通常是因为提供该页面的扩展插件处于停用或卸载状态。不妨前往「插件」页面核实对应的插件是否已正确启用。

**修改了配置项但没有生效**  
第一步确认刚才的修改是否真正点击了保存；第二步确认该设置项是否需要新建会话才能重新加载；第三步前往「场景规则」页面，排查是否存在针对当前上下文优先级更高的特定规则覆盖了全局设置。

**导航栏布局被改乱了**  
无需担心，点击侧边栏底部的管理菜单，选择恢复默认设置，即可一键重置为初始布局。
