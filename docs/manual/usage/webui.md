# 认识 WebUI

::: tip
本节介绍 WebUI 控制台的界面布局、页面功能划分以及通用的配置操作方式。
:::

## 访问控制台

在浏览器中打开 `http://127.0.0.1:5028` 并完成登录。登录后你将进入 WebUI 控制台，界面主要分为两部分：

- **左侧导航栏**：按功能分类排列所有可用页面。
- **右侧内容区**：显示当前选中页面的详情与配置表单。

## 功能页面一览

导航栏中的页面按用途划分为「常用」「能力」和「配置」三个分组：

### 常用功能

| 页面 | 路由 | 作用 |
| --- | --- | --- |
| 聊天 | `/chat` | 与机器人对话的主界面，也是验证配置是否走通的地方 |
| 仪表盘 | `/dashboard` | 实例运行状态总览 |
| 快捷设置 | `/control` | 面向新手的聚合设置页 |
| 场景规则 | `/routing` | 配置路由规则：哪类消息由哪个引擎/角色处理 |
| 表达方式 | `/expressions` | 角色回复风格相关配置 |
| 伪装 | `/character` | 角色人格与外貌管理 |

### 扩展能力

| 页面 | 路由 | 作用 |
| --- | --- | --- |
| 工具 | `/tools` | 查看与开关可用工具 |
| 技能 | `/skills` | 管理可加载的技能目录 |
| 环境 | `/machines` | 配置工具的执行环境（本机 / Docker / SSH） |
| 记忆 | `/memory` | 管理长期记忆条目 |
| MCP | `/mcp` | 接入外部 MCP 工具服务器 |
| 权限 | `/permissions` | 配置权限层级与批准策略 |

### 系统配置

| 页面 | 路由 | 作用 |
| --- | --- | --- |
| 预设 | `/presets` | 管理预设：人格、提示词、外貌描述 |
| 提供商 | — | 添加与管理模型提供商（API Key、基础地址） |
| 聊天平台 | — | 配置平台适配器（QQ、Telegram、Discord 等） |
| 市场 | `/market` | 浏览并安装插件 |
| 定时任务 | `/schedule` | 创建无人值守的定时任务 |
| 后台任务 | `/background` | 查看运行中的后台任务 |
| 轨迹 | `/traces` | 回放每一轮对话的完整过程 |
| 用量 | `/usage` | 查看 token 消耗统计 |
| 日志 | `/logs` | 查看实例日志 |
| 设置 | `/settings` | 外观、语言、访问令牌等 |

## 修改与保存配置

多数配置页面遵循统一的左右分栏操作模式：

1. 在左侧条目列表中选择你需要配置的项目。
2. 在右侧详情表单中修改配置项。
3. 点击「保存」或「启用」按钮提交变更。

::: warning
修改表单后必须点击「保存」或「启用」才会生效。如果配置表单中存在未填写的必填项，该条目将无法启用。
:::
