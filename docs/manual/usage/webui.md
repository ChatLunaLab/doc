# 认识 WebUI

::: tip
控制台是 ChatLuna 的核心管理面板。完成安装后，绝大多数配置修改、状态调试与日常管理都在这里进行，聊天平台仅负责收发消息。
:::

首次启动 ChatLuna 时，终端中会输出控制台的本地访问地址。在浏览器中打开并登录，即可进入控制台主界面。

后续章节会逐一介绍各个独立模块，本节主要带你熟悉控制台的界面布局，了解各项功能的大致分布。

## 打开与登录

在浏览器中访问实例地址即可打开控制台，默认端口为 `5028`。

首次启动时，控制台尚未启用账号体系，而是使用临时访问口令——首启日志中会打印一条包含口令的登录链接，点击即可直接进入。登录后系统会弹出「新手引导」向导，带你完成初始配置：

1. **AI 模型**：连接模型提供商，并选择默认模型。
2. **平台与主人**：连接聊天软件（或先在网页端测试），并将最高控制权认领给你的账号。
3. **做什么用**：选择机器人的职责场景与个性偏好。

上述步骤均可跳过，之后也可以在「设置 → 新手引导」中重新配置。如果你直接在聊天平台上使用机器人，可能会收到一条包含绑定码的消息；在聊天窗口中发送绑定指令和该验证码，即可将自己的聊天账号绑定为最高权限的主人。

::: warning
控制台拥有对整个实例的完全控制权。若要部署在公网环境中，请务必启用登录认证并配置 HTTPS，切勿将未经鉴权的控制台直接暴露在互联网上。
:::

## 界面结构

登录成功后，控制台主界面主要由三部分组成：

- **左侧导航栏**：按功能分类排列的页面入口，用于随时切换视图。
- **顶部栏**：显示当前页面标题、当前登录的账号菜单以及系统通知。
- **右侧内容区**：呈现当前页面的主体内容，包括数据列表、配置表单或详情面板。

左侧导航栏默认划分为六个固定的功能分组：

| 分组 | 放什么 |
| --- | --- |
| **概览** | 仪表盘，用于快速了解实例正在发生的事情 |
| **对话** | 网页聊天交互页面，以及角色的伪装设定 |
| **配置** | 人格预设、模型提供商、聊天平台、场景规则与快捷设置 |
| **插件** | 已安装插件的管理面板与扩展市场 |
| **能力** | 工具、权限、技能、执行环境、记忆与 MCP |
| **系统** | 对话轨迹、Token 用量、系统日志、后台任务与定时任务 |

导航栏中的页面并非固定不变，而是会根据当前安装的插件动态增减。例如未安装 MCP 相关插件时，「能力」分组中便不会显示 MCP 页面。

| 技能 | `/skills` | 查看或导入专属技能包，管理技能目录与覆盖关系 |

浏览器地址栏中的路径支持直接收藏和分享。排查问题时，你可以将某个会话的轨迹页面链接直接复制给协作者，对方打开即可看到完全一致的调试记录（前提是对方同样拥有控制台访问权限）。
:::

## 定制导航栏

左侧导航栏支持自由定制，你可以根据使用习惯调整布局：

- 拖拽任意页面以调整显示顺序
- 将页面拖动到自建分组中集中管理
- 收起或隐藏平时少用的低频页面

如果不小心改乱了布局，随时可以在侧边栏底部的管理菜单中选择「恢复默认布局」，所有页面都会重置回初始位置。

## 三种常见的操作模式

不同页面的具体用途各有不同，但在交互方式上主要可以归纳为以下三类：

### 列表 + 抽屉

大多数管理页面都采用这种布局方案。页面左侧或中央展示一组卡片或数据列表，点击其中一项后，右侧会自动滑出抽屉面板显示详细信息。

抽屉顶部通常放置常用的操作按钮，例如「测试连接」「设为默认」或「删除」；底部则固定着「取消」和「保存」按钮，修改完成后点击保存即可生效。

### 分组表单

像「场景规则」与「快捷设置」这一类设置项较多的页面，通常会将内容组织在多个标签页中，每个标签页聚焦一组相关的配置项。

调整配置后请务必记得点击保存。如果存在未保存的修改，控制台通常会在页面顶部给出醒目的提示，或者在准备切换标签页与离开页面时弹出确认提醒。

### 实时视图

像「聊天」「轨迹」与「日志」这类页面属于实时渲染的动态视图。页面内容会随着机器人的实际运行自动推流更新，无需手动刷新浏览器。

例如在「聊天」页面中，你可以直观看到模型正在生成的流式文本；而在「轨迹」页面里，机器人处理完新消息后，对应的对话记录就会自动出现在列表顶部。

::: warning
点击保存并不等同于所有设置都会立刻在当前对话中生效。不同设置的生效时机存在差异：部分选项在下一句回复时就会起效，而涉及上下文架构的设置则可能需要等新会话建立。页面上通常会有明确的说明文字，配置时请多留意界面提示。
:::

## 仪表盘

仪表盘是登录控制台后默认展示的首页，用于帮助你快速了解实例的整体运行状况。

页面内容由各个启用的插件按需注册的数据卡片组合而成，常见的卡片包括：

- 最近的 Token 消耗与费用走势
- 近期的消息吞吐量与活跃会话数
- 核心服务的运行状态、当前版本号与更新提示

卡片内容会随着安装的扩展插件而丰富。如果不需要某些卡片，可以直接在卡片右上角的菜单中选择隐藏。

## 快捷设置

如果你刚开始接触 ChatLuna，觉得「场景规则」中错综复杂的条件设置有些繁琐，可以先从「快捷设置」入手。

快捷设置将最常用的几组开关按标签页整理在一起，每一项修改都会直接作用于全局默认场景规则：

- **人设**：指定处理消息的引擎，以及机器人扮演的角色预设。
- **模型**：设置默认回复模型与思考深度档位。
- **回复**：配置机器人的接话时机（例如被 @、呼叫名字、私聊直接回复、主动搭话概率等）。
- **工具**：设置工具调用策略（直接向模型提供全部工具、先检索再提供，或通过代码调用）。

在此处保存的修改即为整个系统的全局默认配置。熟悉之后，你可以随时前往「场景规则」页面，为特定的群聊或私聊单独配置覆盖项。

## 设置页

与管理机器人行为的页面不同，「设置」页面专门用来管理控制台本身的基础环境与访问凭证：

- **外观**：在浅色模式、深色模式或跟随系统外观之间切换。
- **语言**：切换控制台的显示语言。
- **访问口令**：修改控制台唯一的登录口令。修改后其他已登录设备会立即下线；脚本调用 API 时需在请求头中携带 `Authorization: Bearer <口令>`。

为了保持侧边栏整洁，「设置」页面在默认状态下处于折叠隐藏状态。你可以通过侧边栏底部的管理菜单或右上角的账号头像菜单快速进入。

::: tip
如果你正在编写脚本调用控制台接口，鉴权所需的 Token 就在此页面生成。该令牌拥有当前账号的全部控制权限，请妥善保管，切勿将其提交到公开代码仓库或发送在公开聊天群中。
:::

## 移动端

控制台针对移动设备做了专门的响应式适配。使用手机或平板的浏览器打开时，页面布局会自动调整为单栏结构：左侧导航栏转为折叠抽屉，复杂的数据表格也会重组为便于触控的纵向卡片。

在移动设备上查看运行状态、审批待办的工具调用或在「聊天」页面临时测试对话都非常流畅。不过对于批量配置规则等精细操作，依然建议在桌面端大屏下进行。

## 常用操作

日常使用 ChatLuna 时，常见的操作场景如下：

**复盘单轮对话细节**  
前往「轨迹」页面找到目标会话并点击对应轮次，即可查看发给模型的提示词、思考链、工具调用的入参与返回值，以及最终送出回复的完整链路。

**临时停用某个工具**  
前往「工具」页面搜索工具名称，将其调用策略直接切换为「禁用」，改动会在下一轮对话中立即生效。

**为特定群聊定制人设**  
前往「场景规则」页面新建一条规则，在作用对象中勾选目标群聊，随后调整需要单独定制的模型或预设项即可。

**安装并启用新插件**  
前往「市场」页面搜索所需插件并点击「安装」。安装完成后跳转至「插件」页面，确认该插件处于启用状态即可开始使用。

**核算今日模型消耗**  
前往「用量」页面，按模型类型或会话分组筛选，即可查看当天的 Token 消耗总量与预估费用。

## 排查

在使用控制台的过程中若遇到异常情况，可以参考以下思路排查：

**无法打开控制台页面**  
检查后台进程是否仍在正常运行；确认默认端口未被其他程序占用；检查本地防火墙或安全组是否放行了该端口。如果部署在公网环境中，还需确认反向代理配置中的端口转发与 WebSocket 代理规则是否正确。

**登录后页面显示空白**  
通常是由于浏览器缓存导致前端静态资源加载失败。可以尝试强制刷新、清除浏览器缓存，或使用无痕模式重新打开。如果仅某个插件页面出现空白，通常是由于该插件与控制台版本存在兼容性差异所致。

**导航栏中找不到某个功能页面**  
提供该页面的扩展插件可能处于停用或未安装状态。前往「插件」页面核实对应插件是否已正确启用。

**修改配置项后未生效**  
1. 确认刚才的修改是否已点击保存。
2. 确认该配置项是否需要新建会话才能生效。
3. 前往「场景规则」页面，排查是否存在优先级更高的规则覆盖了全局设置。

**导航栏布局被改乱**  
点击侧边栏底部的管理菜单，选择「恢复默认布局」即可一键重置为初始状态。
