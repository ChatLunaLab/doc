# 长期记忆

::: tip
本节介绍「记忆」页面的使用方法：机器人如何在跨会话中沉淀事实，以及如何配置记忆的作用域与隔离边界。
:::

长期记忆 (Memory) 允许机器人在跨会话交互中持久化关键事实，例如用户的偏好、约定和历史决策。系统不会把完整的历史对话直接塞入提示词 (Prompt)，而是把提炼出的结构化事实条目写入后端存储；在后续交互中，系统会根据上下文检索相关条目并注入提示词。

## 记忆的生命周期

长期记忆的流转由三个主要阶段构成：

1. **自动提取 (Extract)**：当对话达到一定量级后，系统会自动从近期的消息记录中提炼出有保留价值的事实，并将其写入记忆库。
2. **主动回忆 (Recall)**：当新会话或新轮次对话开始时，系统会检索与当前上下文相关的记忆条目，并动态注入到提示词中。
3. **巩固 (Consolidate / Dream)**：系统会定期对零散、重复或陈旧的记忆条目进行归并与整理。

## 查看与管理记忆条目

如果你需要检查或手动干预机器人所记住的内容，可以在控制台进行维护：

1. 前往「记忆」页面。
2. 在条目列表中查看当前已保存的记忆内容。
3. 点击对应条目进行编辑，或直接删除错误、过时的记忆条目。

::: warning
手动删除记忆条目后将无法通过系统自动恢复。如果删除了关键的用户偏好或约定，机器人将在后续回忆阶段丢失这部分上下文。
:::

## 配置记忆作用域与隔离

每条记忆都绑定在特定的作用域 (Scope) 下，通常由「预设 (Preset)」与「会话 (Session)」共同决定。作用域隔离模式决定了不同会话之间是否能够互相访问记忆。

你可以在记忆设置中调整以下隔离模式：

- **按预设隔离**：绑定到同一预设的所有会话共享这套记忆库。不同会话中沉淀的事实可在该预设下的其他会话中被检索。
- **按会话隔离**：每套会话拥有独立的记忆存储，仅能检索当前会话内提炼的条目，彼此互不可见。

::: tip
如果你的机器人服务于多群聊或多用户场景，且各群聊之间不应互通上下文信息，请将隔离模式设为「按会话隔离」。
:::

## 存储后端

长期记忆支持不同的存储实现：

- **默认后端 (Markdown 存储)**：系统默认使用本地 Markdown 文件存储记忆条目。文件保存在数据目录中，你可以直接通过文本编辑器查看文件内容。
- **向量后端**：当系统中安装并启用了向量后端插件时，记忆检索将走向量相似度匹配（语义搜索），从而支持在大体量记忆条目下进行更精准的回忆。
